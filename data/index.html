    Device

    LD2450 Radar

    Presence stays active for the occupancy timeout after the last target was lost. A target counts as moving while its speed is at least the moving threshold (0 = always moving). With simulation disabled the targets come from the radar via UART (256000 baud). The default pins RX 13 / TX 15 (D7/D8) use the hardware UART, so the USB serial log ends after boot; other pins use a software UART. Pins take effect after a restart.

    Zones

    Sensor at the top, looking down. Drag a corner to resize a zone or object, drag its body to move it. Grid: 1 m.

    A zone appears in Home Assistant only once it is enabled. Min. signal quality ignores targets with a weaker signal in that zone: a higher value means less sensitive, 0 turns the filter off.

    Objects

    Furniture and doors for orientation only, not reported to Home Assistant. The arrow shows the facing direction.

    Illuminance (BH1750)

    No hardware driver yet: with simulation disabled the sensor delivers no data. Pins take effect after a restart.

    MQTT / Home Assistant

    How often the firmware sends the MQTT server a sign of life. Lower = connection losses are detected sooner, higher = more tolerant of short Wi-Fi dropouts.

    How long the firmware waits for a reply from the server before it considers the connection lost. Must be lower than the keepalive.

    Home Assistant Entities

    Disabled entities are removed from Home Assistant. Zone occupancy entities follow the zone's own enabled switch. "Still" is occupancy on with motion off.

    Network

    Some Wi-Fi chips briefly power down to save energy, which delays replies and can cause "Connection lost" messages. Disabling power saving fixes this at the cost of a slightly higher power draw – negligible for a permanently powered device.

    The static IP did not work on the last boots (Wi-Fi or gateway unreachable), so the device is using DHCP. Correct the settings, or cycle the power to try the static IP again.

    Hostname and IP settings take effect after a restart. If the static IP fails three boots in a row, the device falls back to DHCP.

    Forgets the Wi-Fi network and restarts. Connect to the Wi-Fi PresenceTrack-Setup afterwards to choose a network and enter its password.

    Upload Update

    The device is unreachable during the update and the following restart (about 1 minute). Keep this page open.

    Firmware (firmware.bin)
    Filesystem image (littlefs.bin, optional)

    Firmware only: settings are preserved, but the web UI stays at its old version. Filesystem image: replaces the web UI (index.html, app.js, style.css) and erases the saved settings - they are restored automatically from the backup after the restart. Both together = complete release update.

      Restore Backup

      Before every update the browser automatically downloads a config backup (presencetrack-backup-<date_time>.json, in the browser's download folder). Exactly this file can be restored here (/api/config/restore) - it replaces all current settings.
